# Souvik Brahma — Online Resume

This folder contains the GitHub Pages version of the supplied resume.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `resume`).
2. Upload **all files and the `assets` folder** from this folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder, then save.
6. GitHub will provide the public Pages URL.

The resume is designed to preserve the supplied PDF's two-page A4 layout and also adapts for smaller screens.
